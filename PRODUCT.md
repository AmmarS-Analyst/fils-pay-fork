# FilsPay

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users and purpose

FilsPay serves merchants taking payments, buyers using hosted checkout, and
administrators managing merchants and settlement operations. The merchant and
admin surfaces contain dense operational data and real financial actions.

## Constraints

- Preserve the current React applications, routes, permissions and API contracts.
- Preserve financial behavior: integer fils, 1 BD = 1000 fils, Bahrain business days.
- Keep important data easy to scan with compact spacing and accessible controls.
- Use custom interface code; no new component or animation library.

## Brand commitments

The user confirmed the existing FilsPay black/red identity for this modernization.
